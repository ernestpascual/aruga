🧊 3D Motion Projection — whole-human map (Motion3DDots page.tsx:551)

Source & guard

pred_keypoints_3d [70,3] m camera space, real only. has3d = frames[0].pred_keypoints_3d.length≥30 && Array.isArray([0]). If missing → amber banner “No 3D — Modal returned 2D only (no mock)”. Never synth.

Centering & fit

Center = pelvis (hip9+hip10)/2 subtracted; fallback mean70. Scale min(innerW,innerH)*0.38 / maxAbs auto-fits whole body with 22% padding, cy = pad+innerH*0.52. Canvas 320 px, rounded-xl p-4 card, responsive wrapRef width, mobile Y/X split row.

Projection

Orthographic Euler ry=Y°, rx=X°: x1=xcosY−zsinY, y1=ycosX−z1sinX → screen cx+x1*s, cy−y1*s. Depth z2 sorts dots & shades (0.55+0.45*((z+0.8)/1.6), nearer opaque).
