Three consequences

  1. Unauthenticated demo routes are correct design, not a finding. There is no tenant boundary on the judge's laptop; the only video is the one they uploaded. Requiring login would make the project unjudgeable — the only fatal Stage One outcome.
  2. The HIPAA audit is scoped, not retracted. Finding H-1 / P0-1 (agent-route authorization) remains mandatory before any hosted deployment with real patients. It does not apply to a single-user local demo with no ePHI. Never point judges at a hosted URL containing real data.
  3. Two deductions shrink, one grows. The Vercel 60s-vs-Modal-130s timeout does not bind locally; the 39/93 test suite matters only if a judge runs npm test. But docs assuming login/Supabase (docs/DEMO.md, .env.example) now actively mislead the only audience that matters.
"This local demo is intentionally unauthenticated — it runs on your machine with your videos. The production deployment adds Supabase auth, per-therapist ownership gates, and audit logging (HIPAA-audited configuration)." — the sentence to say in the room and print in the README.

Tier B — Inert Locally (document it, don't let judges discover it)

Therapist/client login, submissions, POST /api/agent/biomech/save, goal/highlights runs, SOAP cache — all return clean 503/500 with blank Supabase env. Not broken: that is the production product, out of scope for a Meta-key-only demo. Until the ARUGA_DEMO=1 gate ships (Sprint #2), judges find these by clicking and read "500" as breakage.

The one extra dependency: Modal

Full joint angles need MODAL_MHR_URL — the team's already-deployed Modal endpoint, pasted into the judge's .env.local. Judges must not be asked to modal deploy. Without it, Tier A degrades honestly: SAM + Spark run, biomech returns typed 503 MODAL_NOT_CONFIGURED, no invented angles. If MODAL_SECRET is set on the deployment, unset it for judging or print the value — a 401 reads as a broken demo.

Design Rules for the Unauthenticated Approach

  1. Judge-supplied data only. Demo routes accept uploads and bundled samples; they can never expose another person's records — locally there is no other person. State this property explicitly.
  2. Make demo mode visible. ARUGA_DEMO=1 → banner ("Judge demo — local, unauthenticated, not for patient data") + Tier B nav disabled with a tooltip, documented as forbidden for hosted deployments.
  3. Fail loud and typed, never fake. Missing key → 503 naming the env var; missing Modal → 503; SAM finds nothing → 422 per-concept. No mock-result fallbacks to hit the deadline.
  4. Production story one sentence away (see quote in Recalibration tab). If asked directly: "demo surface auth-free by design; clinic surface gated; agent routes get the same gate before any real deployment." Do not claim that gate is shipped.
